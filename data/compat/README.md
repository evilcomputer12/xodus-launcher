# Compatibility database

`titles.json` maps PC Game Pass titles (by Store ID, the `9XXXXXXXXXXX` product id) to how
they run under Xodus Launcher: a status, notes, and the Wine configuration the launcher
applies when it starts them. The launcher ships this file, refreshes it from
`main` once a day (`~/.cache/xodus-launcher/compat/titles.json`), and lets you override any
entry locally in `~/.config/xodus-launcher/compat/<STOREID>.json`.

`catalog-index.json` is `{StoreId: title}` for every title in the catalog (regenerated by
`scripts/compat-seed.py`), so the database can be diffed against the full Game Pass list.
Titles without an entry run with `defaults` and show as *Untested*.

## Schema (`schema_version` 1)

```json
{
  "schema_version": 1,
  "generated": "2026-10-10",
  "updated": "2026-10-10",
  "defaults": { ...same shape as a title entry, minus title/status/notes/tested... },
  "titles": {
    "9N9PCZWHVP2L": {
      "title": "Warhammer 40,000: Space Marine 2",
      "status": "menu",
      "notes": "plain text shown in the launcher",
      "tested": {"date": "2026-10-10", "launcher": "d22db67", "winegdk": "winegdk-20261010-4afaf0a",
                 "gpu": "AMD Radeon RX 7600 XT (RADV)", "distro": "CachyOS"},
      "runtime": {"wine": "wine-gdk", "min_winegdk": "winegdk-20261010-4afaf0a"},
      "prefix": "shared",
      "dxvk": true,
      "vkd3d": true,
      "env": {"DXVK_HUD": "fps"},
      "dll_overrides": {"xinput1_3": "n,b"},
      "launch": {"executable": "client_pc\\root\\bin\\pc\\Game.exe", "args": [], "eac_bypass": true, "working_dir": ""},
      "winetricks": ["vcrun2022"],
      "registry": [{"key": "HKCU\\Software\\Wine\\Direct3D", "name": "renderer", "type": "REG_SZ", "value": "vulkan"}]
    }
  }
}
```

| Field | Meaning |
|---|---|
| `title` | Display name (informational; the catalog is the source of truth). |
| `status` | `untested`, `broken`, `launches` (starts, no further), `menu` (reaches the menu), `playable` (plays with issues), `perfect`. |
| `notes` | Plain text: what works, what does not, workarounds. |
| `tested` | `date` (YYYY-MM-DD), `launcher` (git short hash), `winegdk` (release tag, or branch@commit for source builds), `gpu`, `distro`. |
| `runtime.wine` | `wine-gdk` (default), `wine-xodus` or another build directory under `~/.local/share/xodus-launcher/<name>/bin/wine`, `proton` (the xodus Proton build), or an absolute path. |
| `runtime.min_winegdk` | Oldest WineGDK release tag the entry was verified with; the launcher warns in the game log when an older release is installed. |
| `prefix` | `shared` (the prefix from Settings) or `per-game` (`~/.local/share/xodus-launcher/prefix-<STOREID>`, created with DXVK/VKD3D on first launch). |
| `dxvk`, `vkd3d` | `false` switches the D3D9-11 / D3D12 DLL overrides to Wine's built-in implementations. |
| `env` | Extra environment variables for the game (applied last, over the launcher's own and Settings' `extra_env`). |
| `dll_overrides` | Merged into `WINEDLLOVERRIDES` (`"dll": "n,b"`). |
| `launch.executable` | Path relative to the game folder that replaces the executable from MicrosoftGame.config. |
| `launch.eac_bypass` | `null` = start the real game instead of the EasyAntiCheat bootstrapper when the game ships one (auto), `true` = same, recorded for reports, `false` = never. |
| `launch.args`, `launch.working_dir` | Recorded; `args` cannot be passed yet (`xodus-cli run` has no argument option), `working_dir` sets the launcher's working directory. |
| `winetricks` | Verbs installed with `winetricks -q` into the prefix once (skipped with a warning when winetricks is missing). |
| `registry` | `wine reg add` entries (`key`, optional `name`, `type`, `value`) applied once per prefix. |

Merge order: launcher built-ins ⊕ `defaults` ⊕ the title entry ⊕ the user's override file. Objects
merge key by key; lists and scalars replace. For the Wine build the precedence is: user override
`runtime.wine` → the title entry's `runtime.wine` → Settings → `defaults` → whatever is installed.

Applied tweaks are remembered per prefix in `<prefix>/.xodus-compat-applied.json`; delete it to
re-apply them.
